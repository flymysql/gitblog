🛠️ 安装说明

🟢 360 极速浏览器（推荐，直接拖拽安装）
1. 下载 360 版 .crx 文件到本地
2. 打开 360 极速浏览器，地址栏访问 se://extensions/
3. 开启右上角 开发者模式
4. 将下载的 .crx 文件直接拖入浏览器窗口，点击「添加」

🔵 Chrome / Edge 浏览器（需解压安装）
1. 下载 Chrome 版 .zip 文件到本地
2. 将 zip 解压到固定文件夹（如 D:\taobao-cert），解压后应能看到 manifest.json
3. 打开 Chrome 访问 chrome://extensions/（Edge 访问 edge://extensions/）
4. 开启右上角 开发者模式
5. 点击 「加载已解压的扩展程序」，选择解压后的文件夹
⚠️ 解压后的文件夹请勿删除或移动，否则插件会失效。
⚠️ 360 若提示「无法从该网站添加应用」，请确认已开启开发者模式后再拖拽。

❓ 常见问题

Q：为什么上传失败/刷不出来订单？

可能原因：页面 DOM 结构变化、网络波动、或历史脏记录。可在后台「清理异常记录」后重新扫描，或导出日志包反馈给我们。

Q：如何添加新店铺？

管理员在后台「白名单管理」添加店铺名即可，插件实时生效，无需重新安装。

Q：证书编号是怎么生成的？

按「前缀 + 随机数字 + 自增序号」生成，序号跨订单连续递增，样式为白底黑字标准检测证书格式。

Q：遇到问题怎么反馈最快？

到「问题反馈」页描述操作步骤和现象，并附上插件弹窗里「导出日志包」生成的 zip 文件信息，我们能快速定位。
